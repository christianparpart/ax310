# Rules

Short, factual notes for whoever picks this project up next — human or model.
Each file is one topic, written so it can be read instead of re-derived. The point
is to stop paying twice for the same discovery.

**These are findings, not style rules.** `AGENT.md` is the rulebook for how code
is written; this directory is for what we know about the hardware, the tooling and
the traps.

| File | What it saves you |
| --- | --- |
| [`hardware-facts.md`](hardware-facts.md) | Established protocol facts, and what is still a guess |
| [`usb-capture.md`](usb-capture.md) | How to capture and decode a single action, with the exact gotchas |
| [`audio-routing.md`](audio-routing.md) | Splitting the deck into per-track devices, and the traps |
| [`device-safety.md`](device-safety.md) | What not to send the deck, and why |
| [`process-traps.md`](process-traps.md) | Mistakes already made here, so they are not made again |
